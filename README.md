# InventJoy website

Static public website files for InventJoy and Healing Paws. Healing Paws is operated by Robert Sweeney under the InventJoy brand. Support: support@inventjoyapps.com.

Intended domain: https://inventjoyapps.com
Prepared privacy-policy URL: https://inventjoyapps.com/healing-paws/privacy.html

This repository has not been published. Its approved HTML, styling and original favicon are preserved exactly. It uses no build step, JavaScript, external scripts, remote fonts, forms, cookies or analytics. Only local styles and icon assets are loaded; email links open a draft at the visitor’s request.

The existing preparation/draft notices and HTML noindex directives remain. robots.txt currently asks crawlers not to index the site; this is not access control. Before publication, approve the final policy and effective date, review hosting/TLS/logging and mail practices, configure professional outbound support sending, and separately authorize any changes to notices and indexing rules. Receive-only support forwarding is working; outbound sending remains pending.

CNAME records the intended custom domain only. It does not configure hosting, DNS or publication. The sitemap lists the intended public page URLs. .nojekyll supports static hosting without a site generator. No hosting platform, account, remote repository or deployment has been configured by this preparation.
